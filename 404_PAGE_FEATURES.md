# 404 Page Features

## 🎨 Amazing 404 Error Page

Your site now has a **stunning, animated 404 page** that turns errors into a delightful experience!

### ✨ Visual Features

#### 1. **Animated Car Illustration**
- Purple SFSU-branded car
- Smooth driving animation (rocks back and forth)
- Animated smoke puffs coming from exhaust
- Drop shadow for depth

#### 2. **Giant "404" Background**
- Huge gradient numbers behind the car
- Bouncing animation (each digit bounces separately)
- Purple to gold gradient
- Semi-transparent for subtle effect

#### 3. **Engaging Copy**
- **Title**: "Oops! Wrong Turn"
- **Message**: "Looks like this page took a detour and got lost"
- **Hint**: Helpful explanation
- Car-themed messaging fits the dealership theme

#### 4. **Multiple Action Buttons**
- **Go Home** - Purple gradient button
- **Browse Cars** - Gold gradient button  
- **Login** - Outlined button
- All with icons and hover effects

### 🎬 Animations

#### Car Animation
```
- Rocks left and right
- Slight rotation for realism
- 3-second loop
- Smooth easing
```

#### Smoke Animation
```
- 3 smoke puffs
- Fade out and drift away
- Staggered timing
- Continuous loop
```

#### Number Bounce
```
- Each digit bounces independently
- Staggered delays (0s, 0.2s, 0.4s)
- Smooth up and down motion
- 2-second loop
```

#### Page Load
```
- Fade in effect
- Slide up animation
- Smooth entrance
```
